\# CareFlow Power BI Dashboard Development



\## Project Overview

CareFlow is a healthcare process analytics project

that analyzes hospital event records and patient pathways.



\## Data Source

\- Source: Hospital event log dataset

\- Total event records: 15,214

\- Unique patient cases: 1,049

\- Total columns: 32



\## Data Preparation

\- Imported the event dataset into Power BI.

\- Reviewed column headers and data types in Power Query.

\- Checked the timestamp field.

\- Applied the data preparation steps using Close \& Apply.



\## Dashboard Development

\- Created the initial Power BI report.

\- Added a KPI for distinct patient cases.

\- Continued developing healthcare performance KPIs

&#x20; and activity-based visualizations.
